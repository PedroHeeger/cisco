<a name="item03.01"><h4>3.1 Introdução</h4></a>[Back to summary](#item03)

📊 Dados, Big Data e Valor Digital   
Os dados são o elemento central das soluções digitais modernas e da Internet das Coisas. Informações geradas por pessoas, dispositivos e sistemas são constantemente coletadas, combinadas e analisadas para produzir conhecimento útil. Este módulo explora como grandes volumes de dados podem ser transformados em valor prático, apoiando decisões estratégicas, otimizando processos e gerando benefícios tanto para empresas quanto para a sociedade.

🎯 Objetivo do módulo   
Explicar como os dados geram valor para os negócios digitais e para a sociedade.

📘 Tópicos do módulo
- O que é Big Data: Apresentar o conceito de Big Data e descreve as principais fontes responsáveis pela geração massiva de dados.
- Armazenamento de Big Data: Explicar os desafios envolvidos no armazenamento de grandes volumes de dados e as soluções utilizadas para lidar com essas demandas.
- Big Data no suporte aos negócios: Descrever como a análise de dados em larga escala é utilizada para apoiar decisões empresariais, melhorar serviços e criar vantagens competitivas.

<a name="item03.02"><h4>3.2 O que é Big Data?</h4></a>[Back to summary](#item03)

📊 Origens e Expansão dos Dados Digitais   
A geração de dados ocorre a partir de uma diversidade de fontes, englobando interações humanas, registros de imagens, textos e atividades em sites. Dispositivos móveis, computadores, tablets e sistemas de automação comercial são os principais emissores dessas informações. Nota-se, entretanto, um crescimento sem precedentes no volume originado por sensores, que agora estão integrados a uma vasta gama de objetos, desde câmeras de monitoramento e semáforos até sistemas de agricultura de precisão.

🔍 O Conceito de Big Data e os Três Vs   
Embora não exista um limite numérico estrito para definir o Big Data, a identificação desse fenômeno em uma organização baseia-se em três características fundamentais:
- Volume: Refere-se à imensa quantidade de dados que exige capacidades de armazenamento cada vez maiores.
- Velocidade: Diz respeito à rapidez com que novas informações são geradas e acumuladas continuamente.
- Variedade: Indica a multiplicidade de formatos em que os dados são apresentados, exigindo diferentes métodos de processamento.

⚡ Escala de Geração de Dados por Sensores   
A capacidade de coleta de dados por sensores modernos atinge proporções massivas. Observam-se os seguintes exemplos de escala:
- Residências Inteligentes: A infraestrutura conectada de uma casa pode produzir até 1 gigabyte (GB) de informações semanalmente.
- Veículos Autônomos: Os sistemas de navegação e segurança de um carro inteligente geram aproximadamente 500 GB de dados por dia.
- Operações de Extração: Sensores em atividades de mineração são capazes de produzir cerca de 300 GB de dados a cada minuto de operação.
- Aviação Comercial: O motor de uma aeronave de grande porte, como o Airbus A380, gera 1 petabyte (PB) de dados — equivalente a um milhão de gigabytes — durante um único voo de longa distância.

📂 Utilidade e Acesso a Dados Externos   
Apesar dos desafios técnicos impostos pelo armazenamento e pela análise de grandes volumes de dados, o Big Data fornece subsídios essenciais para o ajuste de operações e o aumento da satisfação dos usuários finais. A coleta massiva permite identificar padrões que antes eram invisíveis.

É importante ressaltar que a aplicação de análise de dados não está restrita a organizações que geram informações próprias. Empresas de menor porte, que não possuem infraestrutura de sensores ou grande volume de clientes, podem recorrer a conjuntos de dados públicos e gratuitos. Esses recursos externos permitem que qualquer entidade realize análises avançadas e obtenha benefícios estratégicos sem a necessidade de produzir os dados originalmente.

<a name="item03.03"><h4>3.3 Onde o big data é armazenado?</h4></a>[Back to summary](#item03)

📈 Escala Global e Crescimento Exponencial de Dados   
A produção mundial de dados atingiu níveis sem precedentes, com estimativas de que a geração diária alcance 463 exabytes globalmente. Um exabyte corresponde a um bilhão de gigabytes, refletindo uma densidade informativa massiva. O volume gerado a cada minuto evidencia a dependência digital contemporânea:
- Realização de uploads de mais de 500 horas de conteúdo em plataformas de vídeo.
- Envio de aproximadamente 69 milhões de mensagens instantâneas e 198 milhões de e-mails.
- Transmissão de mais de 347.000 GB de dados via serviços de streaming.
- Carregamento de mais de 60.000 imagens em redes sociais fotográficas.

Nota-se que 90% do volume total de dados existentes no mundo foi produzido apenas nos últimos dois anos, caracterizando um crescimento do tipo exponencial que desafia as capacidades de análise em tempo hábil.

💾 Gerenciamento e Segurança em Big Data   
As infraestruturas tradicionais de armazenamento mostram-se insuficientes para acompanhar a demanda atual. Soluções modernas de Big Data exigem não apenas espaço físico ou virtual, mas a implementação de protocolos rigorosos de segurança e resiliência. Para assegurar a integridade das informações, utiliza-se a replicação de dados em múltiplos servidores e data centers distintos. Essa estratégia garante a tolerância a falhas e a redundância necessária para evitar perdas permanentes em caso de incidentes técnicos em nós específicos da rede.

🌐 Arquiteturas de Computação: Borda e Nuvem   
O processamento de dados evoluiu para modelos que priorizam a eficiência de largura de banda e a velocidade de resposta, dividindo-se entre a periferia e o núcleo da rede:
- Computação de Borda (Edge Computing): Utiliza os próprios dispositivos finais ou equipamentos próximos à fonte para realizar o pré-processamento. Esta abordagem reduz a latência e o consumo de banda, enviando para a nuvem apenas os resultados analisados ou dados essenciais para armazenamento de longo prazo.
- Computação em Nuvem (Cloud Computing): Consiste em um ecossistema de servidores interconectados acessíveis via internet. Atua como o repositório central para análise detalhada, backup e fornecimento de software sob demanda.

💻 Impactos e Riscos da Digitalização em Nuvem   
A adoção de serviços em nuvem altera a dinâmica de armazenamento para indivíduos e organizações, apresentando vantagens estratégicas e vulnerabilidades críticas:
- Benefícios Individuais: Liberação de espaço em hardware local e acesso universal a arquivos e aplicativos a partir de qualquer dispositivo conectado.
- Vantagens Corporativas: Redução de custos com infraestrutura física, manutenção e treinamento, além de permitir uma escalabilidade rápida conforme a demanda por dados aumenta.
- Riscos de Segurança: A custódia de informações sensíveis fica condicionada à robustez dos protocolos do provedor escolhido, existindo o risco de acesso por terceiros não autorizados.

⚙️ Processamento Distribuído e Escalonamento Horizontal   
Diferente do dimensionamento vertical, que foca no aumento de potência de um único computador central (mainframe), o processamento distribuído utiliza o escalonamento horizontal. Este método fragmenta grandes volumes de dados em partes menores, distribuindo-as para serem processadas simultaneamente por múltiplos computadores com menor capacidade individual. Esses sistemas de arquivos distribuídos operam de forma transparente para o usuário final, que acessa as informações como se estivessem armazenadas localmente, enquanto os dados estão, na realidade, dispersos por diversos nós da rede.

🐘 O Ecossistema Hadoop   
O Hadoop consolidou-se como o padrão industrial para a gestão de volumes massivos de dados em clusters de computadores. Sua arquitetura é fundamentada em dois pilares principais:
- Hadoop Distributed File System (HDFS): Sistema de arquivos que gerencia o armazenamento distribuído com alta tolerância a falhas.
- MapReduce: Modelo de programação voltado para o processamento paralelo e distribuído de grandes conjuntos de dados.

A eficiência do Hadoop reside na sua capacidade de escalabilidade, permitindo a expansão de poucos nós para milhares de máquinas sem elevar excessivamente a complexidade administrativa. Além disso, a replicação automática de informações entre os clusters assegura que falhas em discos ou racks inteiros não resultem em perda de dados.

<a name="item03.04"><h4>3.4 Suporte aos negócios com Big Data</h4></a>[Back to summary](#item03)

🚀 Dados como Motor da Inovação e Eficiência   
A competitividade no cenário digitalizado exige que as organizações busquem constantemente por eficiência e inovação. A Internet das Coisas (IoT) desempenha um papel central nesse processo, permitindo a coleta e o processamento de volumes massivos de informações. A análise desses dados proporciona uma compreensão profunda sobre o impacto de produtos e serviços, permitindo ajustes estratégicos e a entrega de soluções mais rápidas e qualificadas aos consumidores.

Nota-se que os dados brutos são frequentemente comparados ao petróleo: embora possuam um valor intrínseco elevado, a utilidade real depende de um processo de refinamento e fragmentação. Sem a análise adequada, as informações permanecem em um estado bruto que dificulta a aplicação prática nos negócios.

📊 Categorização de Dados: Transacionais e Analíticos   
O valor organizacional é extraído primordialmente de duas vertentes de processamento informativo:
- Informações Transacionais: São registradas no momento da ocorrência de eventos cotidianos. Sua aplicação foca em relatórios diários de vendas, cronogramas produtivos e gestão de níveis de inventário.
- Informações Analíticas: Destinam-se ao suporte de decisões gerenciais complexas. São fundamentais para determinar a viabilidade de expansões físicas, como a construção de novas unidades, ou a contratação de equipes de vendas adicionais.

A origem desses grandes conjuntos de dados é diversa, abrangendo desde sensores industriais e redes sociais até registros genômicos, metadados de comunicações eletrônicas e arquivos públicos digitalizados.

📂 Estruturas e Formatos de Dados   
As informações coletadas dividem-se em duas categorias principais de acordo com sua organização:
- Dados Estruturados: Originam-se de entradas com formato fixo, como formulários médicos e planilhas. Para garantir a compatibilidade entre diferentes sistemas, é comum a conversão desses registros para formatos universais como o CSV (valores separados por vírgulas), JSON ou XML. Esses padrões facilitam a importação, exportação e integração de dados de fontes variadas.
- Dados Não Estruturados: Apresentam-se em estilo livre, incluindo áudios, vídeos e publicações em redes sociais. Esse tipo de conteúdo exige ferramentas especializadas para a preparação e análise, dado que não seguem uma estrutura tabular predefinida.

🔍 Métodos de Extração e Mineração   
A transformação de dados brutos em inteligência de negócio ocorre por meio da mineração de dados, processo que identifica padrões e correlações em grandes volumes de informação. Para a coleta automatizada, utilizam-se técnicas distintas:
- Captura da Web (Web Scraping): Emprega robôs e rastreadores (crawlers) para extrair informações diretamente de páginas HTML. O objetivo é converter o conteúdo visual das páginas em bancos de dados estruturados.
- Interfaces de Programação de Aplicação (APIs): Utilizam protocolos como o RESTful para estabelecer uma comunicação padronizada entre sistemas. O uso de HTTP e codificação JSON permite que analistas acessem fluxos de dados estáticos ou em tempo real de grandes plataformas digitais de forma contínua.

📉 Visualização e Análise de Valor   
Para que os resultados da mineração sejam úteis aos tomadores de decisão, é necessária uma apresentação visual adequada. A escolha do modelo gráfico depende de variáveis como o volume de pontos de dados, a existência de uma linha do tempo ou a necessidade de comparação entre categorias.
- Gráfico de Linhas: Indicado para demonstrar tendências contínuas ao longo do tempo, como oscilações de vendas ou preços de ações.
- Gráfico de Dispersão: Utilizado para evidenciar correlações e distribuições entre duas variáveis distintas.
- Gráfico de Pizza: Destina-se a mostrar a composição percentual de um valor estático, sendo recomendado para um número limitado de categorias.
- Gráfico de Colunas e Barras: Ideais para comparar valores entre categorias semelhantes, sendo as barras horizontais preferíveis quando os rótulos de dados são extensos.

💡 Estratégias e Ferramentas de Big Data   
A análise de Big Data é definida como o processo de inspeção, limpeza e modelagem de dados para a descoberta de informações úteis. O sucesso dessa operação depende de uma estratégia clara que defina previamente o problema a ser resolvido.

As ferramentas variam conforme a escala do projeto:
- Pequeno e Médio Porte: Utilização de planilhas eletrônicas e ferramentas de análise de tráfego web.
- Grande Escala e Nuvem: Emprego de softwares dedicados como Knime, RapidMiner, Big Query (Google) e ferramentas de análise cognitiva (IBM Cognos).

A aplicação prática dessas análises permite desde a otimização de rotas de coleta de resíduos urbanos até o desenvolvimento de sistemas de monitoramento de saúde em tempo real, evidenciando que os dados não apenas descrevem o presente, mas revelam necessidades e oportunidades para novos serviços e produtos.

<a name="item03.05"><h4>3.5 Resumo de Tudo Gera Dados</h4></a>[Back to summary](#item03)

📦 Características do Big Data   
O conceito é definido pelo tripé de volume, velocidade e variedade, referindo-se a uma quantidade massiva de informações que cresce exponencialmente em diferentes formatos e exige amplo espaço de armazenamento.

📱 Computação de borda   
A arquitetura utiliza os dispositivos finais dos usuários para realizar o pré-processamento e o armazenamento de dados, mantendo as informações próximas à fonte para agilizar a operação.

☁️ Serviços em nuvem   
O sistema consiste em grupos de servidores conectados que oferecem acesso remoto a softwares e armazenamento via internet, reduzindo custos com infraestrutura física e manutenção local.

🧩 Processamento distribuído   
A técnica fragmenta grandes volumes de dados em partes menores que são enviadas a diversos locais, permitindo que múltiplos computadores processem as informações simultaneamente.

🚀 Valor para empresas   
As organizações coletam e analisam volumes massivos de dados sobre o uso de produtos para ajustar objetivos, aprimorar serviços e entregar soluções mais rápidas aos clientes.

🗂️ Tipos de dados   
As informações podem ser estruturadas, como em planilhas, ou não estruturadas, como em mídias sociais, exigindo a conversão para formatos comuns como CSV ou JSON para viabilizar a análise.

🔍 Transformação de informações   
A mineração detecta padrões em dados brutos para gerar conhecimento útil, enquanto a visualização gráfica apresenta esses resultados de forma clara para auxiliar a estratégia gerencial.
