### Objective:
O objetivo deste laboratório é explorar as oportunidades de emprego e de aprendizado no mundo em constante evolução da Internet das coisas (IOT).

### Development:

<a name="item01"><h4>1. Parte 1: Pesquisar Empregos no Campo da Internet das Coisas</h4></a>[Back to summary](#item00)

- a. Abra um navegador da web e pesquise por "tipos de empregos com oportunidades de aprendizado na Internet das Coisas". (Fiz pelo Linkedin)
- b. Você pode incluir outras palavras relevantes, como "aprendizado ao longo da vida" ou até mesmo um título de emprego que você já possa estar interessado. Identifique e documente três designações de emprego em que você está interessado.
  - Especialista IOT/OT (Bradesco)
  - Software Engineer - IoT Applications (TRACTIAN)
  - SRE IoT SR (Turbi)

<a name="item02"><h4>2. Parte 2: Determinar o Conjunto de Habilidades Necessárias para Cada uma Dessas Posições</h4></a>[Back to summary](#item00)

- a. Use um mecanismo de busca para pesquisar títulos de emprego que você identificou como interessantes. Pesquise os conjuntos de qualificações profissionais necessárias para esses cargos. Preste especial atenção às qualificações profissionais necessárias para vários cargos.
  - Redes, Segurança, Clouds, Infraestrutura, Sistemas, Programação, Inglês.

<a name="item03"><h4>3. Parte 3: Explorar Oportunidades de Aprendizado</h4></a>[Back to summary](#item00)

- a. Use um mecanismo de busca e outros recursos disponíveis para pesquisar as oportunidades de aprendizado disponíveis dentro do âmbito desses títulos de emprego. Documente todas as informações coletadas desta pesquisa.
  - Redes: TCP/IP, MQTT, protocolos de comunicação IoT
  - Segurança: autenticação de dispositivos, criptografia, certificados
  - Cloud: AWS IoT, Azure IoT, armazenamento e processamento de dados
  - Infraestrutura: edge devices, gateways, integração com servidores
  - Sistemas: Linux embarcado, RTOS
  - Programação: Python, C/C++
  - Inglês: leitura de documentação técnica e certificações

<a name="item04"><h4>4. Reflexão</h4></a>[Back to summary](#item00)

- a. Há algum padrão observável no mercado de trabalho de IoT?
  - Há um padrão observável no mercado de trabalho de Internet das Coisas (IoT), no qual essa tecnologia atua como uma tecnologia capacitadora em diversos setores da economia. Existem oportunidades de trabalho para profissionais com fortes qualificações em programação, redes e segurança da informação, que contribuem diretamente para o desenvolvimento, a integração e a proteção de soluções de IoT. Além disso, observa-se uma demanda crescente por profissionais com uma compreensão geral de como aplicar essa tecnologia de forma eficiente, segura e estratégica nos diferentes contextos de uso.
