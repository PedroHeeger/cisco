### Development:

<a name="item01"><h4>1. Atividade em Classe - Projetar um Sistema de Comunicação</h4></a>[Back to summary](#item00)

- a. Você deve encontrar uma maneira de trabalhar com a oficina para assegurar que o automóvel seja consertado corretamente. Como você se comunicará com os mecânicos? Projete um modelo de comunicações para garantir que o carro seja reparado corretamente. 
  - A comunicação com os mecânicos ocorreria por meio de um intermediário que fale ambas as línguas, como um tradutor, manuais técnicos ilustrados ou procedimentos padronizados. Esse modelo garante que as informações sobre o problema, o diagnóstico e o reparo sejam transmitidas de forma clara, reduzindo erros e assegurando que o automóvel seja consertado corretamente.

<a name="item01.01"><h4>1.1 Perguntas para reflexão</h4></a>[Back to summary](#item00)

- a. Que etapas você identificou como importantes para comunicar sua solicitação de reparo?  Justifique sua resposta. 
  - As etapas importantes são descrever claramente o problema, traduzir essa descrição para um formato compreensível pelos mecânicos e confirmar o entendimento antes do reparo. Essas etapas são essenciais porque evitam interpretações incorretas, reduzem erros no serviço e garantem que o reparo realizado corresponda exatamente ao problema apresentado.
