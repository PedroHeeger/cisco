### Objective:
O objetivo deste laboratório foi investigar exemplos de violações de segurança da informação e documentar, em formato de tabela, pelo menos cinco casos reais, incluindo detalhes sobre os dados comprometidos, os métodos de ataque utilizados e possíveis medidas de prevenção.
