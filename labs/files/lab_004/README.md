### Development:

<a name="item01"><h4>1. Laboratório - Imagine um novo sensor inteligente</h4></a>[Back to summary](#item00)

- a. Descreva o objeto que selecionou.
  - Janela.
- b. Que tipo de dados os sensores deste objeto coletariam?
  - Sensor de temperatura e Sensor de chuva.
- c. Como os dados coletados poderiam ser úteis e para quem eles seriam úteis?
  - Alertar para fechar a janela em caso de chuva ou queda brusca de temperatura.
  - Proteger o ambiente e melhorar o conforto térmico.

- a. Descreva o objeto que selecionou.
  - Cadeira.
- b. Que tipo de dados os sensores deste objeto coletariam?
  - Sensor de pressão e Sensor de peso.
- c. Como os dados coletados poderiam ser úteis e para quem eles seriam úteis?
  - Detectar há quanto tempo alguém está sentado e emitir um alerta quando a pessoa fica muito tempo sem se levantar.
  - Ajudar a melhorar a postura, evitar dores nas costas e incentivar pausas regulares.
